# tray-run

Запускает консольную команду так, что её окно консоли скрыто (не висит ни на экране, ни в панели задач), а в системном трее появляется иконка. По клику можно показать/скрыть реальное консольное окно команды в любой момент.

## Зачем

Долгоживущие консольные команды (сборки, серверы, watch-процессы, `ping -t`...) занимают окно или панель задач. `tray-run` прячет их, оставляя полноценный нативный консольный вывод — доступный по запросу из трея.

## Использование

```sh
tray-run.exe [--name NAME] [--] <command> [args...]
```

- `--name NAME` — имя для подсказки иконки трея и заголовка окна (по умолчанию — имя команды без расширения)
- `--` — необязательный разделитель; всё после него — команда и её аргументы

Примеры:

```sh
tray-run.exe ping -t 127.0.0.1
tray-run.exe --name dev-server -- npm run dev
tray-run.exe --name build cargo build --release
```

## Управление

- **Левый клик по иконке в трее** — показать/скрыть консольное окно
- **Правый клик** — меню:
  - _Show console / Hide console_ — то же, что левый клик (текст пункта меняется)
  - _Quit_ — завершить и команду, и обёртку
- Когда команда завершается сама, обёртка тоже завершается и иконка исчезает

Окно консоли — настоящее окно `conhost` со стандартным рендерингом, выделением текста, копированием и т.д. — оно просто скрыто, пока не понадобится.

## Сборка из исходников

Требуется Rust (MSVC toolchain) для Windows.

```sh
cargo build --release
```

Готовый бинарник: `target\release\tray-run.exe`. Его можно куда-нибудь положить в PATH.

## Как это работает

- Команда запускается через `conhost.exe` с флагами `CREATE_NEW_CONSOLE | CREATE_SUSPENDED` и `wShowWindow = SW_HIDE` — консоль создаётся, но сразу скрыта
- Окно консоли находится через `EnumWindows` (класс `ConsoleWindowClass`, принадлежащий запущенному `conhost`)
- Ребёнок привязывается к Job Object с `KILL_ON_JOB_CLOSE`, так что при выходе вся дочерняя цепочка гарантированно убивается
- Обёртка — GUI-процесс (`windows_subsystem = "windows"`) — своего окна не имеет; иконка трея и меню нарисованы через `Shell_NotifyIconW` напрямую (windows-sys, без тяжёлых зависимостей)

## Диагностика

Задайте переменную окружения `TRAY_RUN_LOG` с путём к файлу — туда будет писаться отладочный лог:

```powershell
$env:TRAY_RUN_LOG = "$env:TEMP\tray-run.log"
tray-run.exe --name ping -- ping -n 600 127.0.0.1
```

## Ограничения

- Windows only (используются conhost, трей и Job Objects из WinAPI)
- Если команда завершается мгновенно, окно может не успеть найтись — тогда `tray-run` покажет ошибку и завершится
- Одно приложение `tray-run` — одна команда (запустите несколько экземпляров для нескольких команд)
